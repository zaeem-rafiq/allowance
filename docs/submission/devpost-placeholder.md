**Project name:** Allowance

**Tagline (short description):** Your spending rule, enforced inside the PayPal payment, so a hidden line on a web page cannot trick your shopping AI into overspending.

**About the project:**

Allowance lets a parent write a spending rule in plain English, such as "$120 a week, household basics only, nothing over $40 without asking me, never gift cards." Claude turns the rule into a signed mandate. The parent saves PayPal once on PayPal's own sandbox approval page. After that, a Claude Haiku agent restocks the house from a demo store, and every cart is checked against the mandate in plain code before PayPal is charged.

Try to trick it: type a hidden line for a product page, and watch the agent shop. Blocked carts charge $0. Allowed carts are charged to the saved PayPal sandbox account with nobody logged in, and the receipt shows the rule that allowed it.

This is a placeholder. The full write-up, video and screenshots follow before the deadline.

**Built with:** PayPal Payment Method Tokens v3, PayPal Orders v2, Claude Haiku 5.5, Claude Sonnet 5.5, Next.js, Render, PostgreSQL, AG Grid
